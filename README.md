# Link Bio - Nguyễn Gia

## 1. Cài đặt
```bash
npm install
```

## 2. Chạy
```bash
npm run dev
```

## 3. Sửa thông tin
Mở:
`src/main.jsx`

Sửa các giá trị trong `const profile`:
- name
- username
- bio
- avatar
- facebook
- zalo
- instagram
- bank.name
- bank.owner
- bank.account
- bank.qr

## 4. Đưa lên mạng
Sau khi chạy thử:
```bash
npm run build
```
Thư mục `dist` là bản build để deploy lên các dịch vụ hosting như Vercel/Netlify.

## Lưu ý
Không đưa mật khẩu, OTP, CVV hoặc thông tin đăng nhập ngân hàng vào trang.
